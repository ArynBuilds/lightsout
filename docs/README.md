# Lights Out documentation

Lights Out turns your computer off and keeps only your AI agents running: one terminal, your agents and Wi-Fi, at a few watts. On battery that means many more hours of work from the same charge.

It is also a complete terminal for AI agents on Windows, Linux and Mac: rooms, tabs, splits and floating panes, alerts when an agent needs you, tabs that come back with each agent's own conversation, rooms that live on a server, and plugins that can add almost anything.
