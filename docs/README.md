# Lights Out documentation

Lights Out turns your computer off and keeps only your AI agents running: one terminal, your agents and Wi-Fi. On battery that means hours more work from the same charge.

It is also a complete terminal for everyday use, with tabs, rooms, splits and alerts when an agent needs you, on Windows, Linux and Mac.
